## Project Overview

This Excel project analyzes employee productivity using Microsoft Excel.

## Features

- Excel Tables
- Productivity Calculation
- Nested IF Formula
- Conditional Formatting
- Freeze Panes
- Performance Classification

## Formula Used

Productivity

=(Tasks Completed-Errors)/Working Hours

Status

IF(Errors>2,"Needs Review",
IF(Tasks Completed/Tasks Assigned>=95%,"Excellent","Satisfactory"))

## Tools Used

- Microsoft Excel
- Conditional Formatting
- IF Function
- Tables
